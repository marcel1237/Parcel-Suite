# Operação

## Fluxo local

1. Atualize a fonte canônica na raiz ou em `supervised_learning/`.
2. Atualize a síntese correspondente em `GitBook/`.
3. Ajuste `SUMMARY.md` para novos capítulos.
4. Verifique links relativos e Markdown.
5. Rode `git diff --check`.
6. Abra um pull request para revisão e preview no GitBook depois que o Git Sync
   estiver configurado.

Não copie segredos, credenciais, chaves privadas ou caminhos privados
desnecessários para a documentação publicada.
