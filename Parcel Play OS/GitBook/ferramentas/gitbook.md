## Modelo confirmado

GitBook é um serviço hospedado com sites, seções, grupos e páginas. Markdown
é aceito no editor e no fluxo docs-as-code. Git Sync mantém GitHub/GitLab e
GitBook sincronizados; pull requests podem receber previews quando a
integração está configurada.

## CLI

O CLI oficial é `@gitbook/cli`, requer Node.js 18 ou posterior e pode listar
organizações, espaços e páginas. O uso autenticado não foi executado neste
projeto porque não há autorização para conectar uma conta ou armazenar
credenciais.
