## Resultado conhecido

- A ISO Ubuntu Noble + KDE Full foi construída como artefato intermediário.
- O checksum foi calculado e verificado.
- A ISO possui estrutura ISO 9660, catálogo El Torito e entrada GRUB2.
- O boot, o runtime gráfico KDE e o uso híbrido USB ainda não foram
  completamente validados.
- O mdBook existente foi validado separadamente; esta pasta é uma adaptação
  para o fluxo hospedado do GitBook.
