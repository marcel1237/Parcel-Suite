# Mapa da pasta build

`build/` contém resultados de kernels, perfis Live, rootfs, logs, checksums e
staging. Cada família deve ser interpretada junto com sua documentação e seu
baseline; nomes históricos de diretórios não definem a versão técnica.

Não confunda:

- build concluído com boot;
- checksum com funcionalidade;
- presença de driver com compatibilidade de hardware;
- overlay PlayOS com árvore completa do kernel.

Consulte [`INVENTARIO_BUILD.md`](../../INVENTARIO_BUILD.md) para o inventário
detalhado.
