Usuário#1

git clone --depth 1 https://freebsd.org freebsd-src

ChatGPT#2

Esse comando está incorreto porque freebsd.org é o site do projeto, não o repositório Git.

Para clonar apenas o estado mais recente do código-fonte do FreeBSD:

git clone --depth 1 https://git.FreeBSD.org/src.git freebsd-src

Depois:

cd freebsd-src
git status

Se quiser especificamente a branch main:

git clone --depth 1 --branch main https://git.FreeBSD.org/src.git freebsd-src

Isso cria uma árvore com diretórios como bin/, lib/, sbin/, sys/, usr.bin/, usr.sbin/ etc. O --depth 1 baixa o estado atual sem todo o histórico Git.

Usuário#3

tem somente do kernel diretow

ChatGPT#4

Não oficialmente como um repositório Git separado do kernel. No FreeBSD, o kernel fica dentro do repositório src, principalmente em sys/.

Para baixar somente sys/:

git clone --depth 1 --filter=blob:none --sparse https://git.FreeBSD.org/src.git freebsd-kernel
cd freebsd-kernel
git sparse-checkout set sys

Isso deixa essencialmente freebsd-kernel/sys/ com o código do kernel FreeBSD.

Usuário#25

1. Kernel — linux Agora o /sys do freeBSD é equivalente? Em termos de funcionalidades?

ChatGPT#26

Sim, conceitualmente freebsd-src/sys/ é aproximadamente equivalente ao source tree inteiro do kernel Linux.

Exemplos:

FreeBSD sys/kern/  ≈ Linux kernel/
FreeBSD sys/vm/    ≈ Linux mm/
FreeBSD sys/dev/   ≈ Linux drivers/
FreeBSD sys/fs/    ≈ Linux fs/
FreeBSD sys/net*   ≈ Linux net/

A grande diferença é que o freebsd-src também inclui grande parte do userspace/base OS.

Usuário#27

bom acho melhor você comparar o kernel do linux com o source todo do freeBSD, porquê pelo jeito dentro do kernel do linux tem o kernel do kernel, olha lá o nome do diretório.

ChatGPT#28

O repositório linux/ inteiro é o kernel Linux. O subdiretório linux/kernel/ é apenas uma parte interna do kernel.

linux/          ← kernel inteiro
├── kernel/
├── mm/
├── drivers/
├── fs/
├── net/
└── ...

No FreeBSD:

freebsd-src/    ← kernel + base system
├── sys/        ← kernel
├── bin/
├── lib/
├── sbin/
├── usr.bin/
└── usr.sbin/

A comparação mais correta é linux/ ≈ freebsd-src/sys/, e linux/kernel/ ≈ freebsd-src/sys/kern/.
