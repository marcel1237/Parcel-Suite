📀 SESSÃO 4: LIVE CD FREEBSD (2026-08-19)

Pergunta: Como fazer Live CD do FreeBSD?

Descoberta Crítica:
├─ Baseline: FreeBSD 15.1-RELEASE amd64 disc1.iso
├─ Tamanho: 1.35 GB (não cabe CD-R)
├─ Apenas copiar loader.efi NÃO funciona
│  └─ loader precisa localizar /boot, kernel, módulos, rootfs, instalador
├─ Método correto: dentro FreeBSD com release.sh
├─ Código: /release/Makefile, mkisoimages.sh, rc.local
└─ Instalador: usr.sbin/bsdinstall/ (partedit, distfetch, scripts)

❌ Código existe (referenciado) mas NÃO está local no projeto
   └─ Apenas sys/kern foi baixado, não árvore completa
   └─ Necessário: git clone https://git.FreeBSD.org/src.git

Recomendação:
└─ MVP: validar bsdinstall
└─ Futuro: Calamares como frontend
           └─ Backend Parcel-FreeBSD próprio para particionamento
