# PlayOS: Debian 13 (Trixie) KDE Full + Linux Vanilla 7.3-rc4

Este perfil constrói uma Live ISO do PlayOS usando o pipeline nativo Debian `live-build`, combinando o ambiente de desktop completo **KDE Plasma** no userspace do Debian Trixie com o **Linux Kernel Vanilla 7.3-rc4** importado localmente.

## Como Executar
```sh
cd live-build/playos-debian-trixie-kde-full-vanilla-7.3/tools
./build.sh
```
