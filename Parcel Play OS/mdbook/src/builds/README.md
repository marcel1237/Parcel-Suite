# Builds e artefatos

`build/` é um espaço de trabalho, não uma única distribuição. Ele contém
kernels, ISOs, rootfs, logs, caches, fontes baixadas, manuais e resultados de
linhas de experimentação diferentes.

## Documentação associada

O inventário completo e explicativo está em `INVENTARIO_BUILD.md`, na raiz do
repositório. Esta seção apresenta somente a navegação essencial.

## Principais famílias

- kernels Noble e Linux 7.1.8;
- Live Debian Trixie com kernel Noble;
- Graphics Core Noble;
- Native Userspace Stage0/Stage1/Stage2;
- Ubuntu Noble + KDE Full;
- Resolute MVP histórico.
