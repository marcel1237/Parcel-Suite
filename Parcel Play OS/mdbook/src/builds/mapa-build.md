# Mapa da pasta `build/`

| Diretório | Função |
|---|---|
| `playos-ubuntu-noble-kde-full-knoppix-style/` | ISO Ubuntu Noble + KDE Full |
| `playos-debian-trixie-*` | ISOs Debian Trixie com kernel Noble |
| `playos-graphics-core-noble/` | Live Noble XFCE/Calamares |
| `playos-native-stage0/` | userspace nativo mínimo |
| `playos-native-stage1/` | userspace nativo com rootfs tar |
| `playos-native-stage1-iso/` | ISO do Stage1 |
| `playos-native-stage2-graphics/` | logs do estágio gráfico |
| `playos-noble/` | kernel Noble lab |
| `playos-noble-generic/` | kernel Noble Generic |
| `playos-7.1.8/` | kernel Linux 7.1.8 |
| `resolute-mvp/` | staging e resultado histórico |
| `work/` | rootfs e staging de trabalho |
| `manuals/` | guias de criação e branding |

## Regra de interpretação

`output/` normalmente contém resultados promovidos. `work/`, `rootfs/`,
`download/` e `cache/` são áreas intermediárias. Nenhuma delas prova boot por
si só.
