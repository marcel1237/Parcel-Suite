# Categorias de estado

| Estado | Significado |
|---|---|
| `fact` | confirmado em fonte ou execução |
| `inference` | derivado de evidências |
| `decision` | direção aprovada |
| `proposal` | ideia ainda não implementada |
| `implementation` | código ou patch existente |
| `result` | teste ou medição executada |
| `unknown` | não determinado |

Termos como “documentado”, “compilado”, “empacotado”, “inicializado” e
“testado em hardware” não são sinônimos.
