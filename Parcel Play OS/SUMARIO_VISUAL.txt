┌─ CAMADA 6: GLOSSÁRIO E FAMILIA BSD ────────────────────────────────────┐
│                                                                           │
│  EQUIVALÊNCIAS QUE EXIGEM CUIDADO                                       │
│  ├─ Jail ≠ namespace (mais complexo: hierarquia + VNET + RACCT)        │
│  ├─ Namespace ≠ Jail (apenas isolamento de PID/rede/mount)            │
│  ├─ Capsicum ≠ Landlock (fd-capabilities vs LSM filesystem)            │
│  ├─ RCTL ≠ cgroup v2 (políticas distintas)                             │
│  ├─ mbuf ≠ sk_buff (estruturas internas incompatíveis)                │
│  ├─ vnode ≠ inode+dentry (abstrações distintas)                       │
│  ├─ UMA ≠ SLUB (algoritmos distintos)                                  │
│  ├─ bhyve ≠ KVM (interfaces diferentes)                                │
│  ├─ Linuxulator ≠ kernel Linux real (emulação no BSD)                 │
│  ├─ AF_XDP ≠ bpf_zerocopy (mecanismos Linux próprios)                 │
│  └─ ARC/dbuf ≠ page cache Linux (não devem ser misturados)            │
│                                                                           │
│  REGRA: Compare metas, semântica, invariantes, resultados              │
│         Não apenas nomes!                                               │
